# Changelog

## [Unreleased] 
### Added
- Lucid React Icons
- Base UI component library
- `CHANGELOG.md`

### Fixed

### Changed
- Upgrade the primary database to improve query performance.
#### Architecture & Stack
- Switch to a Next.js project structure

#### Documentation
- `README.md` and `CONTRIBUTION.md` updated with appropriate instructions

## [1.0.0] - 2026-03-30
### Added
#### Features
- Womens' Directory
- Profile Page
- Nomination form
- Self submission form
- Submit story page
- News Page
- Admin dashboard for managing nominations
- Sanity CMS Integration for managing articles.

#### Architecture & Stack
- **Frontend**: HTML, CSS, JS. Deployed on Netlify
- **Backend**: Node + Express. Hosted on Render.
- **Database**: Supabase
- **Content Management System (CMS):** Sanity for handling article management.
